# Seasonal state block

Seasonal state block

## Usage

``` r
seasonal(
  name,
  period,
  type = c("Trigonometric", "Crude", "HarrisonStevens", "Dummy"),
  variance = 0.01,
  fixed = FALSE
)
```

## Arguments

- name:

  Name of the block

- period:

  Period of the seasonality

- type:

  Type of the seasonal component

- variance:

  Innovation variance

- fixed:

  Indicates if the variance is fixed
