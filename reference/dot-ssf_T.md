# Gets the transition matrix.

Gets the transition matrix.

## Usage

``` r
.ssf_T(x, pos = 0)
```

## Arguments

- x:

  A state block or a state space form.

- pos:

  The 0-based position (use 0 for time invariant models)

## Value

The requested matrix.

## Examples

sarima<-.sarma(12, .9, -.6, .9, -.5)
