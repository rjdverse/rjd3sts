# Gets the loading vector. It should have the same length as the corresponding state block.

Gets the loading vector. It should have the same length as the
corresponding state block.

## Usage

``` r
.ssf_Z(x, n, pos)
```

## Arguments

- x:

  Loading

- n:

  the Length of the corresponding state block (on which the loading will
  be applied)

- pos:

  0-based position of the filter

## Value

the loading vector
